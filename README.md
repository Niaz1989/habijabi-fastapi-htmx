# FastAPI + HTMX Multi-Auth System

একটি আধুনিক এবং সুরক্ষিত ফুল-স্ট্যাক প্রজেক্ট যা **FastAPI**, **HTMX**, এবং **Tailwind CSS** দিয়ে তৈরি করা হয়েছে। এই প্রজেক্টে কোনো ভারী জাভাস্ক্রিপ্ট ফ্রেমওয়ার্ক ছাড়াই পেজ রিফ্রেশমুক্ত রিঅ্যাক্টিভ ইউজার ইন্টারফেস তৈরি করা হয়েছে।

## ফিচারসমূহ
* **ইউজার রেজিস্ট্রেশন:** পাসওয়ার্ড হ্যাশিং (`pwdlib`) এবং প্রোফাইল পিকচার আপলোড সুবিধা।
* **JWT + HttpOnly Cookie লগইন:** ব্রাউজারে সুরক্ষিত টোকেন সেশন ম্যানেজমেন্ট।
* **রোল-বেসড এক্সেস (RBAC):** ইউজার এবং অ্যাডমিনদের জন্য আলাদা ড্যাশবোর্ড ভিউ।
* **লাইভ অ্যাডমিন টেবিল:** পেজ রিফ্রেশ ছাড়াই ইনলাইন এডিট, সেভ, ক্যানসেল এবং ডিলিট অপারেশন।

## ইনস্টলেশন এবং রান করার নিয়ম

১. ডিপেন্ডেন্সিগুলো ইনস্টল করুন:
   ```bash
   pip install -r requirements.txt
   ```
২. `backend` ডিরেক্টরি থেকে সার্ভারটি রান করুন:
   ```bash
   uvicorn server:app --reload
   ```
